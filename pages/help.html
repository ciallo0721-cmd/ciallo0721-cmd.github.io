关于 Cloudflare 错误
本站使用 Cloudflare 提供 CDN 加速和安全防护。当你访问本站时，如果遇到错误页面，通常是 Cloudflare 返回的。下面列出了最常见的 Cloudflare 错误码及其含义和解决方法喵～
Cloudflare 常见错误码
CF 1020 Access Denied — 访问被拒绝

Cloudflare 防火墙拦截了您的请求。常见原因：IP 信誉评分过低、使用了代理/VPN、浏览器指纹异常，或请求头不正常。

💡 解决方法：① 关闭 VPN/代理重试；② 清除浏览器 Cookie 后刷新；③ 换用无痕模式或另一个浏览器；④ 切换网络（如用流量代替 WiFi）。
Cloudflare 官方文档
CF 1015 Too Many Requests — 请求过于频繁

您在短时间内发送了太多请求，触发了 Cloudflare 的速率限制（Rate Limiting）保护机制。

💡 解决方法：等待 5–15 分钟后再访问，期间避免频繁刷新页面。正常操作不会触发此限制。
Cloudflare 官方文档
CF 1010 Access Denied — 浏览器特征异常

Cloudflare 检测到您的浏览器特征（User-Agent、JS 指纹等）与正常用户不符，判定为可疑请求。

💡 解决方法：① 确保浏览器已启用 JavaScript 和 Cookie；② 不要使用过时或魔改版浏览器；③ 换用 Chrome/Firefox/Edge 最新版本重试。
参考解决方案
CF 1000 DNS 解析错误

Cloudflare 无法解析域名指向的源服务器，通常是 DNS 配置问题或源站 IP 变更导致。

💡 解决方法：尝试刷新 DNS 缓存（Windows: ipconfig /flushdns）后重试，或等待站长修复 DNS 配置。
Cloudflare 官方文档
HTTP 标准错误
500 Internal Server Error — 服务器内部错误

服务器端程序出错，常见于代码 bug、服务器配置错误或临时资源耗尽。

💡 解决方法：稍后刷新重试。若反复出现，请联系站长。
MDN 文档
502 Bad Gateway — 网关错误

反向代理（Cloudflare/CDN）无法从源服务器获取有效响应，源站可能离线或过载。

💡 解决方法：等待几分钟后刷新重试，通常是临时性问题。
MDN 文档
503 Service Unavailable — 服务暂时不可用

服务器暂时无法处理请求，通常是因为正在维护、过载，或正在遭受 DDoS 攻击。

💡 解决方法：稍后重试。如果是 GitHub Pages 托管，可能平台正在维护。
MDN 文档
504 Gateway Timeout — 网关超时

代理服务器等待源服务器响应时超时，通常是服务器处理请求耗时过长。

💡 解决方法：刷新页面重试即可，通常为临时性问题，几秒后自动恢复。
MDN 文档
404 Not Found — 页面不存在

请求的页面或资源不存在，可能是链接错误、页面已被删除或 URL 输入有误。

💡 解决方法：检查 URL 是否正确，或从首页重新导航进入。
