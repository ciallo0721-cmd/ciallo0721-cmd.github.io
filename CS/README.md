# fy_iceworld · 5v5 团队死斗（单文件 FPS）

仿 CSGO `fy_iceworld` 风格的蓝白做旧第一人称射击小游戏。HTML + 外链 `../js/js/CS.js`（游戏逻辑），Three.js 走 CDN，无任何本地图片/音频依赖。玩家（默认蓝队）率 4 名 AI 队友，对抗 5 名红队 AI，团队死斗；用 `?spy=1` 可切换为红方。

## 玩法

- 地图为正方形小型竞技场，自上而下分三区：顶部 `[ ]` 敌方出生区、中部 `| |` 中立交战区、底部 `{ }` 我方出生区。
- 柱子和四周矮墙作掩体，蓝白马赛克像素纹理 + 低分辨率渲染 + 噪点叠加做旧。
- 武器：AK47（自动/30发）、手枪（半自动/12发）、手雷（×2，延时范围爆炸）。命中用射线检测，开火有后坐力，换弹有延迟，音效 WebAudio 合成。
- **击倒≠死亡**：被击倒后倒地可缓慢爬行，队友靠近按住 `E` 救援（红方 AI 同样会救人）；救援期间不能开枪，敌方可以偷袭正在救人的目标。
- **团灭即胜负**：一方全员倒地（无人存活）即判负，弹出胜负结算可「再来一局」。
- **医疗箱**：场地 5 个位置刷新绿十字医疗箱，走过去自动拾取回血，拾取后 12 秒原地刷新。

## 操作

**桌面端**
- 移动：`W` `A` `S` `D`
- 视角：鼠标（点击画面锁定指针）
- 射击 / 投掷：鼠标左键
- 换弹：`R`　切换武器（AK→手枪→手雷）：`F`　救援倒地队友（按住）：`E`
- 飞天（需开启）：`=` 上升、`-` 下降
- 核弹（需开启）：`0`
- 暂停 / 灵敏度：`Esc`（暂停菜单内拖动旋钮调鼠标灵敏度）

**手机端**
- 左侧虚拟摇杆移动，右侧三键：`开枪` `换弹` `换枪`
- 切到手雷后用「开枪」投掷；靠近倒地队友自动救援（无需按键）
- 右上角 `⏸` 暂停、`🔗` 分享

> 设备模式可用开始界面的「切换为手机/桌面」按钮手动改，或用 URL 参数 `?isphone=T` / `?isphone=F` 强制。

## 背景音乐

- 曲目：`assets/sound/bgm.mp3`（*Killers* · Kevin MacLeod · incompetech.com · **CC BY 4.0**，可商用但需署名——暂停面板内已标注）。
- 逻辑在 `assets/code/bgm.js`，**自包含、不改游戏主逻辑**：靠观察 `#overlay` / `#pause` / `#victory` 的 `.hide` 推游戏状态——开始界面停、游戏中淡入、暂停停、结算压低音量续播。
- 受浏览器自动播放策略限制，**首次必须要一次点击才出声**；点「点击开始」即自动解锁，之后无需再点。
- 右上角 `🎵` 一键静音 / 恢复；暂停面板第二行是音量滑块。音量与静音存在 `localStorage`（`bgmVolume` / `bgmMuted`，同源下与 HRAI 共享）。
- 换曲子：直接替换 `assets/sound/bgm.mp3`（文件名别改）。改默认音量 / 结算压低系数：`index.html` 里的 `window.BGM_CONFIG`。
- 控制台可手动接管：`BGM.setVolume(0.2)`、`BGM.play()`、`BGM.pause()`、`BGM.stop()`、`BGM.state()`。

## 自定义键位（保存在本机浏览器）

对局中按 `Esc` 或 `` ` `` 打开暂停设置，新增两个入口：

- **⌨ 键盘键位**：点某项右侧的按键 → 按下想绑定的新键即可（`Esc` 取消）。和已有键位撞车时会自动交换，「恢复默认」一键还原。
  可改动作：前进 / 后退 / 左移 / 右移、跳跃、蹲下、换弹、换枪、救援·下包·拆包、飞↑、飞↓、侦查无人机、自爆无人机、核弹。
- **👆 手指键位**：自动进入 DEBUG 沙盒地图（空场、不会被打）并开启编辑态，**点住任意触屏按键拖到任意位置**，点 **💾 保存** 写入浏览器；**↺ 恢复默认** 还原出厂布局；**✔ 完成** 退出编辑。
  可摆的键：左摇杆、开枪、换弹、换枪、飞↑、飞↓、蹲、跳、侦察、自爆。

> 两项都存 `localStorage`（`csKeymap` / `csTouchLayout`），只在本机浏览器生效，换设备或清缓存会回到默认。手指键位按**视口百分比**保存，横竖屏切换、换分辨率都不会跑位。

## 枪械配置（CS/assets/Guns/all.json）

所有枪的参数都在这一个 JSON 里，**改完刷新就生效，不用动代码**。数组、对象两种写法都认（对象写法用 key 当 `id`）。

**必填字段**

| 字段 | 说明 |
|------|------|
| `id` | 内部编号，必须唯一。换枪循环、代码索引都靠它 |
| `name` | HUD 上显示的名字，中文英文都行 |
| `bullets` | **总弹量**（弹匣 + 备用的总和） |
| `initial` | **弹匣容量**，打完这么多就得按 `R` 换弹；备用弹 = `bullets − initial` |
| `hit` | 伤害值，范围 **1~200**（填超了自动钳到边界） |
| `sound` | 开火音效文件名，放在 `CS/assets/sound/` 下 |
| `special` | 特殊功能，见下表；多个用逗号组合（如 `"boom,track"`），没有就留空 `""` |

**special 可选值**

| 值 | 效果 |
|----|------|
| `""` | 无 |
| `boom` | **爆炸**：走弹道 + 范围伤害（RPG、手雷） |
| `cold` | **凝固**：命中目标 3 秒内移速减半（玩家和 AI 都吃） |
| `perspective` | **透视**：命中目标 5 秒内头顶显示穿墙红标 |
| `track` | **追踪**：火箭锁定 40m 内最近的敌人 |

**可选字段**（不填就用默认值）

| 字段 | 默认 | 说明 |
|------|------|------|
| `interval` | 0.3 | 射击间隔（秒），越小越快 |
| `reload` | 1.5 | 换弹耗时（秒） |
| `auto` | false | true = 按住连发，false = 点一次一发 |
| `range` | 60 | 射程（米） |
| `rays` | 1 | 一次射出的弹丸数（霰弹 = 5） |
| `spread` | 0 | 散射弧度（霰弹 0.22、狙击 0.015） |
| `radius` | 8 | 爆炸半径，配 `boom` 用 |
| `bot` | 同 `hit` | AI 拿这把枪时的伤害，想削弱 AI 就调低 |
| `hidden` | false | true = 不出场、不进换枪循环（狙击枪默认如此） |

**加一把枪**：往数组里加一项就行，换枪循环、弹药初始化、AI 随机配枪会自动带上它。

```json
{"id":"laser","name":"激光枪","bullets":50,"initial":25,"hit":7,"sound":"shoot_pistol.wav","special":"cold,track","interval":0.05,"auto":true}
```

> JSON 读不到时（例如直接双击 `file://` 打开被浏览器 CORS 拦），会自动退回 `gun.js` 里的内置兜底表，游戏照常能玩。

## 秘籍（URL 参数）

在 `CS/index.html` 后追加 `?参数=值` 即可，可组合，例如：

```
CS/index.html?imagod=1&gztfxxm=1
```

| 参数 | 效果 |
|------|------|
| `?imagod=1` | **外挂全开**：无敌（被打不扣血反而加血）+ 无限子弹 + 飞天。可理解为作弊全开。 |
| `?fireinthehole=1` | 无限子弹（弹匣不减，HUD 显示 `∞`）。 |
| `?chinesecanfly=1` | 飞天：游戏中按 `=` 上升、`-` 下降（限高 45）。 |
| `?hospital={数值}` | 无敌血量：设定玩家初始/重生血量，如 `?hospital=9999` 几乎打不死。 |
| `?pvp=1` | **1v5 模式**：玩家单独对抗 5 名敌人（无蓝队队友）。 |
| `?try=1` | **5v1 模式**：我方（玩家+4队友）对抗仅 1 名敌人。 |
| `?gztfxxm=1` | **⚠️ 慎用！** 召唤核弹：游戏中按 `0` 触发，全图敌方重创，我方 +1000 分。 |
| `?sorry=1` | **误伤友军**：开启后玩家的子弹可以打到同阵营队友（打队友），击杀提示照常显示「友军」。 |
| `?spy=1` | **间谍模式**：玩家阵营切换为红方，与红队 AI 并肩对抗蓝队；击杀计入红方分数，开始界面文案同步变为红方。 |

已启用的秘籍会在游戏顶部状态条显示。

## 修改器菜单（免打参数）

嫌手敲 `?参数` 太麻烦？在开始界面连点标题里的 **「5v5」** 文字 **5 下**，会弹出独立的「修改器 Trainer」窗口：

- 勾选想开的秘籍，点 **「实时应用」**——无敌 / 无限子弹 / 飞天 / 误伤友军 / 核弹 即时生效，不用重开。
- **间谍 / 1v5 / 5v1** 会改变阵营与出生配置，点「实时应用」会提示需重开，自动用对应参数刷新游戏；或直接点 **「应用并重开」** 一次性套用全部勾选项。
- 窗口关闭即失效（刷新游戏也重置），本质还是把勾选项翻译成上面的 URL 参数。

> 弹窗被浏览器拦截时，先允许本页弹出窗口再点。

## DEBUG 沙盒（测试用）

开始界面标题里 **「.」**（5v5 前面的点）连点 **10 下** 进入 DEBUG 沙盒：同一张地图、初始**空无一人**，可自行召唤单位、手动击倒、触发胜负，用来测救人 / 医疗箱 / 团灭等系统。

**桌面快捷键**（进沙盒后生效，移动/射击仍可正常用）
| 键 | 效果 |
|----|------|
| `;` | 召唤红方（敌人） |
| `'` | 召唤队友（蓝方） |
| `.` | 击倒一名红方 |
| `,` | 击倒一名蓝队队友；场上无队友时改为击倒自己（测试被救） |
| `-` | 切换 飞天 + 无限子弹 + 100 血 |
| `Y` | 直接弹出胜利界面 |
| `N` | 直接弹出失败界面 |
| `H` | 在玩家正前方生成医疗箱 |

**手机端 / 通用按钮**：进沙盒后屏幕左侧出现 DEBUG 控制面板，上述功能均有对应按钮（召唤红方 / 召唤队友 / 红方击倒 / 队友·我击倒 / 飞天外挂 / 面前急救包 / 直接胜利 / 直接失败 / 退出 DEBUG），手机无实体键盘也能完整操作。

> 沙盒下**不会自动判胜负**（空场不算赢），只有点「直接胜利/失败」或正常堆满倒地才触发结算；点「再来一局」会清空重开沙盒，「退出 DEBUG」刷新回正常游戏。

## 备注

- 玩家在 code 层面隐身（仅保留摄像机视角），避免自己的身体方块挡住视线；AI 仍能正常侦测并交火。
- 所有角色身前有黑色枪杆标识朝向（一眼分辨谁在打你）；玩家第一人称右下角有枪贴图，开枪会后座抖动。
- 渲染分辨率缩放默认 `RES_SCALE=0.5`（核显/弱机优先流畅），可用 `?high=1`(0.75) / `?low=1`(0.45) 手动调；配合 CSS `image-rendering: pixelated` 实现做旧像素风。
- 改完如需上线，按博客工作流 `git push` 部署到 GitHub Pages 即可，访问 `你的域名/CS/`。
