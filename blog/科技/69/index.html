CMD —— 命令提示符，Windows 的灵魂之窗

那个黑底白字的窗口，见证了从 MS-DOS 到 Windows 11 的整个计算机发展史。它也恰好是我 GitHub ID 的最后一个组成部分。

发布日期：2026-07-28
阅读时间：约8分钟

在 Windows 系统里，有一个从 1981 年活到现在的老古董。它没有华丽的界面，没有漂亮的图标，只有一个黑底白字的窗口和闪动的光标。

它就是 CMD（命令提示符，Command Prompt）。

你也许觉得它很古老、很落后——毕竟现在都有 Windows Terminal 了，谁还用那个黑框框？但 CMD 的历史地位和它的实用价值，远比你想象的要厚重。

CMD 的前世今生

MS-DOS 时代（1981-2000）

CMD 的"祖宗"是 MS-DOS（Microsoft Disk Operating System，微软磁盘操作系统）。在 Windows 出现之前，电脑的操作系统就是这个黑屏 + 命令行。没有鼠标，没有窗口，你要运行一个程序就得输入命令：

C:\> dir
C:\> copy a.txt b.txt
C:\> format a:

在那个年代，会打命令就是会用电脑。Windows 95 出现后，图形界面开始普及，但 MS-DOS 仍然作为底层存在——你可以从 Windows 中"退出到 MS-DOS"。很多老游戏（比如仙剑奇侠传 DOS 版）就是在 DOS 下跑的。

Windows NT 时代的 CMD.EXE

到了 Windows NT（包括 XP、7、10、11 等），微软提供了一个名为 cmd.exe 的程序来模拟 DOS 的命令行环境。它并不是真正的 DOS，而是一个"命令行解释器"——这就是我们今天说的 CMD。

你可以在 Windows 的任何版本里按下 Win + R，输入 cmd，回车，召唤出这个黑窗口。它在今天仍然被大量使用：

  • 开发者用 CMD 运行 Git 命令、编译代码、执行脚本
  • 系统管理员用 CMD 进行网络诊断（ping、ipconfig、tracert）
  • 普通用户用 CMD 修复系统、清除 DNS 缓存、查看网络状态

几个常用的 CMD 命令

这里介绍几个最实用的命令，就算你不是开发者，也可能会在某天用到：

:: 查看 IP 地址和网络配置
ipconfig

:: 测试网络连通性（ping 百度）
ping baidu.com

:: 查看目录下的文件
dir

:: 切换目录
cd 文件夹名

:: 清除 DNS 缓存（网站打不开时试一下）
ipconfig /flushdns

:: 查看路由追踪
tracert baidu.com

你可能会发现，CMD 的命令语法和 Linux 的终端（bash）有很大的不同——Windows 用 dir 而 Linux 用 ls，Windows 用 cd 而 Linux 也用 cd（这个一样）。CMD 的反斜杠 \ 路径分隔符和 Linux 的正斜杠 / 也经常让人混乱。

CMD 的局限性

说句公道话，CMD 确实有年代感了。和 PowerShell 或者 Linux 的 bash 相比，它缺乏很多现代 shell 的功能：

  • 管道处理能力弱——PowerShell 传递的是对象，CMD 传递的是文本
  • 脚本语法古老——批处理（.bat）语法写起来很痛苦
  • 不支持远程管理、不支持正则表达式等现代功能

所以如果你深入做开发，大概率会转向 PowerShell 或 Windows Terminal。但 CMD 作为一个"最低门槛的命令行入口"，它的简单性和兼容性是无可替代的——几乎任何 Windows 电脑上都能用，不用装任何额外软件。

💡 冷知识

· CMD 的完整路径是 C:\Windows\System32\cmd.exe

· CMD 可以通过按 F7 键调出历史命令列表

· 在 CMD 中按 Tab 键可以自动补全文件名和路径

· 用 doskey /history 可以导出当前会话的所有命令历史
