## 引子：一个人，两个名字

今年十一月，B 站有一个账号改了名。

从「游乐园在前面左边」，改成「誓死报效祖国-李雪」。

改名的理由，她自己在评论区解释过：中华血脉醒了。

我上一次写她，就是那个「游乐园在前面左边」。那时候她的观点很简洁：男生写的书全是垃圾，女生写的书全是神作。她把全世界的作者按身份证分成两堆，一堆扔掉，一堆供起来。（旧文在此：[《锐评"BV1yRFQzqEyo"和"游乐园在前面左边"这个人》](../../心理学/80/index.html)）

那篇文章的结尾我写过一句话，大意是：读书，从来不看户口本。

三个月后，她把户口本换了。敌人也换了。但从头到尾，她看世界的方法一个字都没改。

她还是把巨大的、复杂的、充满灰度的世界，压进两个格子里。上一次的格子是「男 / 女」，这一次的格子是「爱国 / 反贼」。

换了敌人，没换脑子。

先把话说在前面：这不是一篇政治评论。

政治太大了。大到一旦开始争论「谁更爱国」，所有人都会输，包括写的人。

我关心的东西小得多，也具体得多——一个人脑袋里的结构，在换了一个话题之后，会不会跟着换。

答案是不会。这就是我要记录的全部。

## 一、这半年，她发了些什么

不必我说，看标题就够了。

「双面人上野千鹤子（更讨厌日本人了」

「一部分女权真的让我很失望，这不是女权，是分裂分子」

「遍地美军基地，遍地细菌战实验室，哪里好？」

「中国的空气都是甜的～」

「中国遥遥领先」

「中国魂」

「报效祖国」

「中国精神」

「女性主义不能脱离民族精神」

十条里九条是同一个主题，同一个情绪，同一个方向。从十月底到十一月初，几乎日更。

其中两条我放在这里，因为标题本身已经说明了一切：

她不写别的，也不许别人写别的。

有人说过一句很普通的话：中国的军事力量大概和美国在一个量级。这句话已经足够克制，足够正面，甚至带着善意的判断。她的反应是专门做一期视频去骂那个人是傻子。

这就是第一个信号。一个人如果对自己的立场有底气，就不需要为一个「并列关系」动怒。她动怒，说明她要的不是「我们很强」，而是「我们唯一」。

我本来还想再往下列，但我停住了。因为我不想把自己的账号权重交给这个话题，也不想让首页从此变成一个我不认识的地方。她的投稿页在 [这里](https://space.bilibili.com/488890474/upload/video)，想看的人自己去看。

这些标题里有一个共同的动作，值得单独拎出来说。

她反复用「没有美军基地」这件事作为起点。这个事实是真的：中国境内确实没有外国驻军基地。但她的用法不是「这一项我们做得好」，而是「所以这里一切都完美」。

这是一个很典型的偷换。一个具体的、可以核对的事实，被当成了全称判断的凭证。就像一个人考了一次满分，从此认定自己所有的题都不会错。

还有一条要单独拎出来，就是《中国魂》。

那一期里，她讲了一件事：有些人没有读过「领导人写的书」，她为此感到悲哀。

我先把话说明白，免得被曲解：那些书本身没有任何问题。书就是书，它值不值得读，跟谁写的没有关系，也跟谁在读没有关系。我要拆的从来不是书，是她的那个反应。

「你没读过这本书」和「你不好」之间，没有必然联系。

读书是私事。一个人的书架，是由他的兴趣、专业、经历和时间共同决定的。一个痴迷科幻的人没读过某本政治著作，一个钻研代码的人没读过某本文学理论，这不构成任何道德缺陷，更不构成任何立场问题。

可她把这个动作做成了审判：你不读，所以你可悲；你可悲，所以你应该读；你不读，所以我就有心寒的理由。

==
这里有一件很讽刺的事：把一本书变成忠诚度测试，是对那本书最大的不尊重。一本书的力量在于它的内容能说服人，不在于读过它的人数能证明人。当「读过」变成一种资格审查，这本书就从思想降格成了徽章。
==

而徽章是用来别在胸口的，不是用来读的。

三个月前，她用性别判断书。现在，她用「读没读过某本书」判断人。动作一模一样，只是审查表格换了一张。

一句话总结：无脑爱国，加上政治学整体跑偏。

## 二、她骂过的东西，她现在自己在做

这一节是全文最硬的部分，因为不需要我攻击她。

回到三个月前那篇。「游乐园在前面左边」当时指控男作者犯了四条罪。我把她今天的视频一条条对上：

**第一条罪名：只着眼于宏大叙事，只写宏伟，不写人。**

她当年原话大意是：他们只关心自己的宏大叙事，把眼光永远朝向金字塔的顶端，从来不看底层的人。

而她今天的标题是：《中国精神》《中国魂》《报效祖国》《中国遥遥领先》。

宏大叙事是什么？她当年骂的那个东西是什么？她自己做出来的，比任何一个被她骂过的作者都要宏大。整个民族，整个文明，整个东方，整个五千年——一个人能站多高就站多高，能说多大就说多大。

**第二条罪名：不给过程，直接甩结论。**

她当年原话大意是：这群人写书，就给你甩一个结论，告诉你我的观点就是这样，没有过程。

而她今天的视频，标题本身就是结论。《中国遥遥领先》《中国的空气都是甜的》。没有数据，没有对比，没有论证链，甚至没有具体的人具体的事。只有一个结论，外挂一段情绪。

**第三条罪名：夹带私货，用自己的经历给自己背书。**

她当年的原话是：男作者特别爱夹带私货，随时吹自己见过多少世面、去过多少地方、是什么学历，好让你相信他很厉害所以他说得对。

而她解释改名的理由是：中华血脉醒了。

这句话的信息含量是什么？一，我身上有某种古老的血统；二，这个血统正在觉醒；三，所以我的判断有资格被信任。这不叫论证，这叫出示家谱。

**第四条罪名：用身份证代替阅读理解，只会贴标签。**

她当年骂的正是这一条。她用性别当遥控器，按一下「男」，跳过所有文本分析。

现在她换了个遥控器，还是同一个动作。按一下「爱国」，你就赢了；按一下「反贼」，你就该闭嘴。评论区里的每一次判定，都不是文本分析，都是身份核查。

==
四条罪名，一条不落，全部复现。她不是在批判一种方法，她是在把那种方法从头到尾学了个遍，然后换了个方向继续用。
==

我甚至不需要判断她的人格。我只需要把她自己的两条时间线并排放着。它们会自己打架。

## 三、二极管没换，只换了插头

她的方法论，从第一天到今天，只有一个动作：把世界压缩成二极。

心理学里管这个叫二分法思维（dichotomous thinking），辩证行为疗法把它列为情绪失调的核心认知模式之一：世界只有全好和全坏，人只有全对和全错，中间那片巨大的灰色地带，被整块删掉。

这个动作有三个特征。

**第一，只需要站队，不需要思考。**

「男作者全是垃圾」——你只需要回答一个选择题：你是男作者还是女作者。回答完了，观点就自动生成了。

「爱国还是不爱国」——同样是一个选择题，答案只有两个选项，中间没有空白。

人一旦习惯这种结构，就会开始害怕需要推理的事情。因为推理意味着要区分，要判断，要在两难里待着。而待着很累。贴标签只要一秒。

社会心理学里有个词叫「认知吝啬鬼」：人处理信息时天然倾向于走最省力的路。而二分法是所有路径里最省力的一条——它不需要你理解对方，只需要你给对方盖章。

**第二，只给结论，只给结果。**

她的每一条视频，都是从一个已经被她当成公理的东西出发的：我们这儿很好。剩下的部分不是论证，是举例，是抒情，是向观众重复那句公理。

一个真正的观点需要被证明。而一个不需要证明、只需要被复述的观点，本质上不是观点，是口号。

**第三，没有「例外」这两个字。**

这是最要命的一点。她的世界里，不存在「大多数男作者不行，但这位可以」；也不存在「这个国家有很多好的地方，也有许多值得改进的地方」。

不，她把每一件事都推到全称判断上。

逻辑学里叫全称判断，心理学里叫过度概括。两个词指向同一件事：从一两个样本，直接跳到整个世界。

而维持全称判断唯一可行的办法，就是不断开除反例。所以她的体系必须留一个出口，专门用来把不配合的人送出去——那个出口就是最后那一招：你不够爱国。

**最讽刺的地方在这里。**

她指责别人搞分裂的时候，她自己每天在做的事是什么？她每天在男女之间划一条线，然后把这条线画得越来越粗，越来越深。她说别人分裂民族，而她自己分裂的是这个民族的一半人和另一半人。

她反对的从来不是分裂，她反对的是别人在她的分裂之外，也画了一条线。

## 四、表演过头的爱国，消耗的是「爱国」这个词

我看过她的视频。

有一种很奇怪的感觉，我说不清楚，后来想明白了：反串感。

这不是因为她说错了什么。她的很多结论甚至是事实：中国的治安确实好，基建确实快，中国确实不是战区。这些都不假。

问题不在内容，在密度和频率。

一天一条，条条顶格，情绪永远在沸点，语调永远在高潮。你听着听着就会产生一种怀疑：一个人真的可以每天都这么激动吗？

一个人如果每天都这么激动，那他激动的大概率不是那件事，而是激动本身能带来的东西。

==
真正的热爱，不需要日更九条来证明。需要不停表演的东西，通常是需要变现的东西。
==

她讲的那些道理，来源很统一：都是别人写好的、现成的、已经封装成结论的书。她把这些结论搬过来，再配上情绪，做成视频。

这没有问题，人都是这样学习的。但这里有一个缺口：

**她有二手结论，但没有一手经验。**

她有没有自己去过一个县城，看过一个村子，跟一个具体的人坐下来聊过两个小时？她有没有在任何一件具体的小事里，感受过这个国家真实的、粗糙的、带着汗味的质地？

她的视频里没有这种人。只有大词。

而一个从没自己走过一段路的人，复述一万句结论，也还是站在原地。

==
这里必须说清楚一件事，否则文章会被误读：我不是在说「爱国不对」，也不是在说「批评才高级」。我说的是，爱国不是免检章。
==

越是真心爱的东西，越该容得下具体的批评，因为批评的目的不是毁掉它，是让它更好。

这中间有一条很清楚的界线，我们这代人应该都还记得那条线。

心理学里有个概念叫道德执照（moral licensing）：人在做了一件自己认为正确的事之后，会觉得手上多了一张许可证，接下来做别的事，哪怕明显越界，也心安理得。

「我在爱国」这四个字，就是最容易签发这种执照的印章。

2012 年，很多人上街表达对另一个国家的愤怒。其中有人举着 U 型锁，砸向了同胞的车，砸穿了同胞的头骨。

那些人当时也觉得自己在爱国。他们的嗓门比谁都大，情绪比谁都满，口号比谁都响。

可他们最后伤害的是谁？

==
爱国一旦变成一场表演，它消耗的不是外国，是「爱国」这个词本身的信用。
==

每多一个靠这个赛道吃饭的人，真正想认真说点话的人，说话就更难。因为那两个字已经被喊得廉价了。

## 五、为什么「扣帽子」对她无效

她的护身符只有一个：你不爱国。

你只要开始解释「我其实也爱国」，你就输了。因为解释这个动作本身，就等于承认她有资格审你。

所以有几件事，根本不需要回应：

她是不是中国人，她爱不爱国，以及——你爱不爱国。

这三件事一旦开始自证，你就已经在她的场子里打球了。而她的场子里，球网是歪的。

==
该回应的只有一件事：她的论证在哪一步断了。
==

比如她说「中国的空气都是甜的」。这句话的问题不在于它是否动听，而在于它不可证伪。地球上不存在任何证据能让这句话变成假的，那它也就不是一句可以被讨论的话。它是一句抒情，被当成了论据。

比如她说「女性主义不能脱离民族精神」。这句话的问题不在于立场，而在于它把一个描述性的概念（女性主义）和一个规范性的要求（民族精神）硬绑在一起，然后把不接受这个绑定的人定义为敌人。这是定义偷换，不是观点交锋。

再比如她面对那个说「中美军力在一个量级」的人。她没有指出对方哪里说错了，她的处理方式是，做一期视频，宣布对方是傻子。

==
她要的从来不是辩论。删评是舞台管理的动作，一个真要辩论的人不会删评，因为评论是他的材料。
==

删评的人只说明一件事：这里不是辩论场，是舞台。而舞台上不允许有观众走上台。

真正的辩手怕的是论据不够，演员怕的是台词被抢。

## 六、这不是政治问题，是认知问题

说到这里，我得把自己的话也摆出来，不能只站在旁边挑刺。

**我当然支持她爱国。**

爱国是每个公民的权利，也是义务，也是责任。不分种族，不分国界，人对自己生长的地方有感情，这不需要论证，这是本能。

但爱国不是喊出来的，是做出来的。

是你在自己的工作里少糊弄一点，是你看到不公平时敢说一句，是你把身边具体的人当人看，是你让这个国家因为你而好了一点点。

批评和热爱从来不冲突。

一个国家的自信，恰恰体现在它能容下多少不同的声音。一个需要靠删评来维持的自信，不叫自信，那叫紧张。

==
我不反对她爱国。我反对的是她把爱国做成一门流量生意，然后顺手把所有不买账的人都打成敌人。
==

她读了很多书，我承认。但读书的目的是让人更能分辨，不是让人更会站队。如果读完一堆书，最后只是把「我们永远正确」这句话说得更响亮，那这些书算是白读了。

所以这篇文章从头到尾，问的都不是「她爱不爱国」。

问的是另一个问题：一个人的判断系统，如果只装得下两个格子，那么无论这两个格子叫什么名字，它都会把世界切错。

今天这两个格子叫「男 / 女」，明天叫「爱国 / 反贼」，后天可以叫任何东西。

标签一直在换，刀从来没换。

这才是我想说的全部。

## 结语：快恢复二极管

回到那个名字。

改名字很容易。改一个 ID，换一个头像，十分钟的事。

改脑子很难。因为脑子里的那个结构，是很多年一点点长出来的，它藏在你判断世界的每一个动作里。

她换了名字，换了敌人，换了赛道，换了口号。唯一没换的，是那个只会用两个格子看世界的脑袋。

顺着这个思路，我想给她一个更准确的技术称号。

普通二极管，只允许电流往一个方向走。它的升级款叫快恢复二极管，英文 Fast Recovery Diode，缩写 FRD。名字听着很厉害，恢复得快，反应也快。

但它还是二极管。

一个方向，永远只有一个方向。反向电压加得再大，它也只会截止。

==
名字换了，封装换了，参数标得漂亮了。正向压降还是那个正向压降。
==

最后一句，送给还在往前跑的人：

看她，不如自己出门走一段路。

路会告诉你，世界从来不是两个格子。
