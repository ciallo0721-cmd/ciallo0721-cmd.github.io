# 我破解了我的小鲨鱼

> 分类：教程 · 2026-10-23 · 标签：破解 / 解包 / Construct 3 / 我的小鲨鱼



<p>《我的小鲨鱼》是 Steam 上一款小品级的国产恐怖养成游戏。表面上你养一条方块小鲨鱼，喂食、锻炼、开灯关灯，多周目下来才会发现它讲的是完全另一个故事。游戏用 Construct 3 制作，发行版是一个 36 MB 的 Tauri 打包 exe。</p>
<p>这篇文章记录我把这个 exe 整个剥开的过程。不是提取几个图片音效就收工，而是把里面的 Construct 3 工程文件<strong>完整还原</strong>了出来：20 个布局、20 张事件表、158 个对象类型、128 个配音与 BGM、29 张精灵图，一个不少。</p>
<h2 id="_1">成果：整个 C3 工程被剥了出来</h2>
<p>解包得到的单文件 HTML 可以直接双击运行，游戏完整可玩。本地原版文件加了一个开幕提示，明示这是解包版本、不要分发：</p>
<div class="article-image-container"><img src="images/01-dir.jpg" class="zoomable" alt="解包出的 c3 工程目录"><div class="image-caption">图 1：解包产物的工程目录，images / media / scripts / box2d.wasm / data.json 一应俱全</div></div>
<h2 id="_2">解包原理：三层套娃</h2>
<p>这个 exe 是典型的「套娃」结构，从外到内三层，每层用的都是官方标准格式，所以剥起来反而干净利落。</p>
<h3>第一层：Tauri 外壳</h3>
<p>exe 本体是 Rust 编译的 PE 文件，运行时是 <strong>Tauri 1.5.4</strong>（Rust + 系统 WebView2）。判断依据很直接：.rdata 里能翻出 <code data-plain="tauri-1.5.4/src/manager.rs">编译路径字符串</code> 和 <code data-plain="__TAURI_IIFE__">前端注入的 API 桥</code>。前端资源在 Tauri 里以 asset 形式嵌进二进制，用 phf 静态 Map 管理。</p>
<h3>第二层：brotli 压缩的 index.html</h3>
<p>.rdata 中段有一块 30 MB 的高熵数据（0x34C000–0x2138000），这是整块压缩后的前端。定位方法是在其末尾找 phf 资源表，里面只有一条记录：</p>
<pre><code>"/index.html" -&gt; ptr=0x14034D49B, len=0x1DEC2B9</code></pre>
<p>也就是偏移 0x34C49B 起、长 31,376,057 字节的一段 brotli 流。Tauri 的 <code data-plain="EmbeddedAssets::get()">资源读取函数</code> 本身就是用 brotli 解压的，照方抓药即可：解出来是一个 44.8 MB 的完整 index.html。</p>
<h3>第三层：c3_base64files</h3>
<p>这个 HTML 是 Construct 3 的「单文件导出」格式，内部结构是：</p>
<pre><code>self.c3_base64files = {
  "scripts/c3runtime.js": { "type": "application/javascript", "str": "..." },
  "data.json":            { "type": "application/json",      "str": "..." },
  "box2d.wasm":           "data:application/wasm;base64,AGFyZ...",
  "images/xx-sheet0.png": "data:image/png;base64,iVBORw0KG...",
  ...
}</code></pre>
<p>脚本文件是明文 JS 字符串，二进制素材是 base64 data URI。用 Node 把这个对象 eval 出来再逐条落地，165 个工程文件全部还原，PNG / WebM / WASM 均通过文件头校验，无一损坏。</p>
