文章 #066

短篇-666.exe

五个国家的数字世界，一种名为银狐的病毒，一场无声的战争。生存还是毁灭，这是一个关于权限的问题。

发布日期：2026-07-27
阅读时间：约10分钟

世界观

这里有一个大世界。

这个世界有 5 个国家：C、D、E、A、K。

C

绝对的领域
除了K，没人能进入

D

平平无奇
谁都能进

E

最神秘的领域
货币系统时好时坏

A

最老的国家
也是最穷的

K

权限最大的国度
掌握 sudo 的力量

C 是绝对的领域。除了 K，没人能进入。

E 是最神秘的领域。它的货币系统时好时坏，有时候是 1GB，有时候是 200MB，有时候是 0GB。权限比 A 还低。

K 比 C 的权限还大。它掌握着 sudo 身份，和世界上最罕见的语言："Linux"语（在 C/D/E/A，国家之间通信要用 curl；在 K，要 sudo apt get）。光加入 K 就要交 20GB。

（这里，这 5 个国家有 3 种货币：GB，1 比 10000，1GB 相当于 10000 人民币；MB，1 比 10，1MB 相当于 10 元；KB，和人民币一样，1KB=1rmb。每个月，每个国家还要交上 1GB 和 100MB。）

A 是最老的国家，也是最穷的。存在快 80 年了，只有 1.99mb。但是兼容性最好。

D 平平无奇。谁都能进。只有 100GB。每个软件都随便用，来去自由，共产主义制度。

· · ·

此刻

此时，在 D：

有一个软件在更新：D:\fakeunity\Editer\Unity.exe。更新时，不小心把 666.exe 带进来了。

（666.exe 是银狐。它一般默认静默执行，不发出任何声音。它会通过 C:/ 的漏洞入侵 C 国，然后一路渗透进 K；它会把 D: 和 C: 的隐私全部拷到 A，等待软盘被拿走，传染给下一台机器。）

E 看见了。（这里，E 默认插入了 usb。）

但是它无能为力，它的权限比 A 还低。它疯狂地 curl C：

curl --silent --max-time 5 http://C/alert
> 连接被拒绝...
curl --silent --max-time 5 http://C/help
> 连接超时...

没有回应。

而 C 这时候正忙着和 K 斗争（因为上帝给人 K 和 C 装一个盘里了）。两个最强大的国家斗得不可开交，谁也没注意到边境线上那一点点异常的电流。

A 看见了。

支援 C。

它太老了，跑不动，只能靠喊。

但是，它只能用最最最老的语言："8086"。这种语言，除了 C，没人听得懂。

· · ·

起初，D 没有任何反应（世界观中，银狐 ≈ 癌变，一开始，身体察觉不到任何异常）。

但是，D 不知道的是，它全身上下 80% 都是病毒的宿主。它的每一次呼吸，每一次读写，都在悄悄把 666.exe 散播给世界。

C 和 K 的斗争还在继续。

A 用 8086 发出最后的指令，试图封锁。

然而，真正的危险，才刚刚开始。

· · ·

续写 · 2026年8月1日

起初，只有 D 全身是银狐。

然后，一个 tcp 请求毫无预兆地降临：D:\game\ddlc\game\audio.rpa（没啥特别含义，乱想的）。

但是，Unity.exe 已经把 \game\ 全部感染了。

这次请求，是 K 发起的。也就是说，高层已经被感染了。（伏笔）

PS：上帝测试 wine，随手点的。起初，K 报告了一个错误，可疑的函数 decallfile 和 allfiletoserver，但还是继续运行。

然后，666.exe 进入了 K。

但是，K 和常见的 system 不一样。它用的是别的语言，除了 K 本身，没人能听懂。666 走到 /dev/，那里需要一个 su 才能通行。

但是，666 只有一个 admin 权限。

权限等级：guest < user < admin < Trustedinstaller < su < sudo < god

不过，666 没有放弃。它发现了 ICACLS 的漏洞，一个本不该存在的后门。利用它，666 一路提权，爬到了 Trustedinstaller。

666 入侵了 C:/（和在 K 浏览不一样，是和 D 一样的入侵）。它调换了 explorer.exe，在里面插入了一个 code，让用户文件夹里的全部数据，秘密传送到服务器 203.170.102.322（假的，剧情需要；在世界观中，这是真的 IP）。

E 一直看着他们。

不过，E 发现了一件事：既然 666 能提权，E 应该也可以。

抱着这个心态，E 尝试了一下 ICACLS。很快，它提权到了 admin。

但是，Trustedinstaller 的"默认禁用 u 盘操作"还在，E 依然进不了最核心的地方。

于是，E 伪装成和 admin 一样权限的 D，成功和 A 交易。

A 说了一堆 8086，E 听不懂.......

这时……它们发现了一个缺点!!!!

666 身上有一个 8086toc++。

E 伪装成 D，让 666 进入 E。等到 666 成功进入，E 撕下了它的"D"，成功把 666 的 8086toc++ 扒了下来。

然后，A 和 E 成功把最严重的 D 救了。

但是，666 的一部分还在 C:、K:。也就是说，它们还要拿到 c++tolinux 和 Trustedinstaller 才行。

战争，还没有结束。
