# HRAI · Horror AI 恐怖逃生（单文件恐怖追逐）

基于 CS（fy_iceworld 5v5 团队死斗）改造的**单人恐怖逃生**小游戏。HTML + 外链 `CS.js`（游戏逻辑），Three.js 走 CDN，无本地图片依赖。

## 玩法

- 你被困在黑暗的冰封竞技场里，浓雾吞没了视野（能见度约 40m）。
- 全场只有 **1 个敌人「它」**：持小刀（伤害 **200**，一刀秒杀 100 血），永远锁定你的位置、会绕柱子追你。
- 生路：收集散落在全场的 **20 把钥匙盒** → 去右侧房屋的 **合成台** 合成 **大钥匙** → 穿过「它」出生区后方（北墙中段）的 **大门** 逃出去。
- **钥匙盒**：靠近按 `E` 开启。收集等待时间按剩余数量递减：前 5 把**直接收集**（剩 >15 把）→ 剩 15~6 把等 **2 秒** → 剩 5~2 把等 **10 秒** → 最后 1 把等 **30 秒**。中途被追走开，**进度保留**，回来继续。
- **撬棍**：B 点房间（右侧房屋）内有一把，靠近按 `E` 拾取，之后**开启钥匙盒速度 +20%**（30 秒那把变 24 秒）。
- **狂暴**：当只剩最后 **3 把钥匙** 时，「它」进入狂暴——全图锁定你、速度提升（约 5.9 m/s，仍比你慢，但追得紧）。平时它只在 **22m 内** 感知到你，跑远了就甩丢，会去你最后的位置傻乎乎地找一会儿，然后四处游荡。
- **脚步声**：「它」走路时发出低沉声响（shoot_ak.wav），**音量随距离衰减**，34m 外听不见——雾里听声辨位，跑近就说明它来了。
- **失败**：被小刀击中即被终结，无队友、无救援。

## 操作

**桌面端**
- 移动：`W` `A` `S` `D`　视角：鼠标（点击画面锁定指针）
- 跳跃：`空格`　蹲下：`C`
- 交互（收集 / 合成 / 开门）：`E`
- 暂停 / 灵敏度：`Esc`（暂停菜单内可调鼠标灵敏度、改键位）

**手机端**
- 左侧虚拟摇杆移动，右侧「蹲」「跳」按钮，拖拽屏幕看视角
- 靠近钥匙盒 / 合成台 / 大门 **自动交互**，无需按键
- 右上角 `⏸` 暂停、`🔗` 分享

> 设备模式可用开始界面的「切换为手机/桌面」按钮手动改，或用 URL 参数 `?isphone=T` / `?isphone=F` 强制。

## 背景音乐

- 曲目：`assets/sound/bgm.mp3`（*Ossuary 5 - Rest* · Kevin MacLeod · incompetech.com · **CC BY 4.0**，可商用但需署名——暂停面板内已标注）。默认音量 0.26，比 CS 更轻，不抢氛围。
- 逻辑在 `assets/code/bgm.js`，**自包含、不改游戏主逻辑**：靠观察 `#overlay` / `#pause` / `#victory` 的 `.hide` 推游戏状态——开始界面停、游戏中淡入、暂停停、结算压低音量续播。
- 受浏览器自动播放策略限制，**首次必须要一次点击才出声**；点「点击开始」即自动解锁，之后无需再点。
- 右上角 `🎵` 一键静音 / 恢复；暂停面板第二行是音量滑块。音量与静音存在 `localStorage`（`bgmVolume` / `bgmMuted`，同源下与 CS 共享，即改一处两处生效）。
- 换曲子：直接替换 `assets/sound/bgm.mp3`（文件名别改）。改默认音量 / 结算压低系数：`index.html` 里的 `window.BGM_CONFIG`。
- 控制台可手动接管：`BGM.setVolume(0.2)`、`BGM.play()`、`BGM.pause()`、`BGM.stop()`、`BGM.state()`。它快追上来时想加紧张感，也可以 `BGM.setVolume(0.5)` 临时拉高。

## 自定义键位（保存在本机浏览器）

对局中按 `Esc` 或 `` ` `` 打开暂停设置：

- **⌨ 键盘键位**：点某项右侧的按键 → 按下想绑定的新键（`Esc` 取消）。和已有键位撞车时会自动交换。
- **👆 手指键位**：自动进入 DEBUG 沙盒地图并开启编辑态，**点住任意触屏按键拖到任意位置**，点 **💾 保存** 写入浏览器；**↺ 恢复默认**；**✔ 完成** 退出。

> 两项都存 `localStorage`（`hraiKeymap` / `hraiTouchLayout`），只在本机浏览器生效。

## 参数

| 参数 | 效果 |
|------|------|
| `?high=1` | 渲染分辨率 0.75（更清晰） |
| `?low=1` | 渲染分辨率 0.45（更流畅） |
| `?isphone=T/F` | 强制手机 / 桌面模式 |

## 核心数值（CS.js 顶部可调）

- `TOTAL_KEYS = 20`：钥匙盒数量
- `keyWaitTime()`：收集等待分级（剩>15把=0s / 剩15~6=2s / 剩5~2=10s / 剩1=30s）
- `RUSH_LEFT = 3`：剩几把钥匙触发狂暴
- `RUSH_MUL = 1.65`：狂暴速度倍率
- `CRAFT_TIME = 5`：合成大钥匙秒数
- 敌人：平时速度 3.6（狂暴×1.65）、感知 22m（狂暴全图）、挥刀距离 2m、冷却 1s、伤害 200；脚步声 shoot_ak.wav，音量 = 1 − 距离/34
- 撬棍：B 点房间 (25,-2)，拾取后 keyWaitTime ×0.8
- 雾：`FOG_NEAR=10` `FOG_FAR=42`　渲染距离：`CAM_FAR=45`

## 备注

- 渲染分辨率缩放默认 `RES_SCALE=0.5`，可用 `?high=1` / `?low=1` 调；配合 CSS `filter: brightness(0.92)` 实现暗化。
